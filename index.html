Como ler este painel

Leitura dos dados

  • Percentuais dizem quantos, a cada 100, estão em uma situação. "7 em cada 10" é o percentual arredondado para a dezena.
  • Base é o grupo a que o percentual se refere. Ela aparece no rodapé de cada cartão e muda entre os indicadores.
  • Margem de erro é a faixa em que o valor real provavelmente está, porque a pesquisa entrevista uma amostra. Passe o cursor ou toque numa barra para vê-la.
  • Traço escuro nas barras marca o valor do Brasil quando um recorte está selecionado.
  • Pictogramas: a figura de pessoa representa gestores; o prédio representa escolas.
  • Sexo, cor ou raça e idade são recortes do gestor e não existem nas tabelas de escolas. Respostas "Não respondeu" ficam fora do filtro.

Princípios de design aplicados

  • Pictogramas no lugar de números soltos, em que cada figura vale uma fração fixa do total, como no Isotype. Elementos pictóricos ajudam a reter a informação (Bateman et al., 2010).
  • Uma cor de destaque para a resposta principal e tons neutros para o resto. Categorias em ordem (idade, velocidade, frequência) usam tons de uma só cor.
  • Frases antes dos gráficos, em linguagem simples, para quem tem menos letramento em dados (Knaflic, 2016; Spinillo, 2023).
  • Integridade: base e margem de erro sempre visíveis e barras a partir do zero, para não induzir a erro (Dastani, 2002).
  • Feito para o celular: tudo cabe numa coluna e funciona ao toque (Spinillo, 2023).
